# SmartStick

> 基于 STM32F103C8T6 的智能辅助导盲杖原型（Demo v1）

面向视障人士出行辅助的低成本电控平台：以单颗 **STM32F103C8T6** 为主控，集成超声避障、
姿态跌倒检测、本地声/震报警、OLED 状态显示与手扶牵引控制，并配备串口 shell 便于现场
调试与参数标定。

## 功能概览

| 功能 | 实现硬件 | 优先级 |
|---|---|---|
| 正前方避障（分级减速 / 停车 + 提示） | 超声波模块 ×1 | P0 |
| 姿态与跌倒检测 | MPU6050（I²C） | P0 |
| 本地报警（声音 + 震动） | 有源蜂鸣器 + 振动马达 | P0 |
| 状态显示（距离 / 姿态 / 电量 / 错误码） | 0.96" I²C OLED | P0 |
| 手扶牵引（双电机差速） | L298N + GA25-370 DC12V ×2 | P0 |
| 电池电压监测 | ADC + 电阻分压 | P1 |
| 蓝牙透传 / 磁力计校准 / 按键 | 接口与驱动骨架预留 | P2 |

## 开发环境

- **STM32CubeMX**（HAL 库，HSE → PLL → 72MHz，Toolchain：MDK-ARM V5）
- **Keil MDK5**
- **ST-Link**（SWD 烧录 / 调试）
