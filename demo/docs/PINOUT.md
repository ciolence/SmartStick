## 3. STM32 复用约束核对（配置前自查）

| 约束 | 说明 | 本方案的处置 |
|------|------|--------------|
| **SWD 占用** | PA13/PA14 必须留给 ST-Link | 已保留，无冲突 |
| **PB3/PB4/PB15/PA15 默认是 JTAG 引脚** | 复位后默认功能为 JTDO/NJTRST/DI/DO | CubeMX 中 `System Core → SYS → Debug = **Serial Wire**`；**不要**选 `JTAG 5-pin`。选 Serial Wire 后 PB3/PB4/PA15 自动变回普通 GPIO，PB4 才能当按键用 |
| **I²C1 固定引脚组** | SCL=PB6 / SDA=PB7（本封装无重映射） | 已按此分配；不会与 UART/TIM 冲突 |
| **USART1** | TX=PA9 / RX=PA10（默认组） | 已用；PA9 也是 TIM1_CH2，本项目不用 TIM1 |
| **USART2** | TX=PA2 / RX=PA3（默认组） | 已用；PA2/PA3 同时也是 TIM2_CH3/CH4 与 ADC 通道，本项目不用这些复用 |
| **USART3** | TX=PB10 / RX=PB11（默认组） | 已用；无冲突 |
| **TIM3 通道映射** | CH3=PB0 / CH4=PB1（默认，无重映射） | 两路 PWM 同频（同一个 TIM3），**本项目正需要同频差速调速**，无需独立频率 |
| **TIM4 用途** | 4 通道 16 位定时器 | 用于**微秒级计时基准**（超声波 Echo 测宽/超时），不占引脚 |
| **TIM1 冲突** | PA8 是 TIM1_CH1，但 TIM1 不宜再分（本项目不用 TIM1） | 舵机预留先走**软件 PWM**；若后期要硬件 PWM，改挂 PA5（TIM2_CH1） |
| **PA0/PA1 复用** | TIM2_CH1/CH2、EXTI0/1、ADC_IN0/1 | 第二路超声波预留：Trig 当普通输出，Echo 走 TIM2_CH2 输入捕获或 EXTI 双边沿 + TIM4 计时 |
| **PB2 = BOOT1** | 默认已下拉，可用作 GPIO 但会影响启动模式 | **保持不用**（留作可靠启动） |
| **PC13/PC14/PC15** | PC13 驱动能力弱（≤3mA），PC14/15 是 LSE 晶振脚 | PC13 只驱动 LED；PC14/PC15 接板载 8MHz 晶振（HSE）**禁改** |

## 4. 电源树与供电

### 4.1 电源拓扑（关键变更：电机为 DC12V）

```
                    ┌─────────────────────────────────────────┐
   12V 电池组 ──┤ 电源开关 + 5A 保险丝                        │
  (3S 锂电组/12V)  └─────────────┬───────────────────────────┘
                                 │
                 ┌───────────────┴────────────────┐
                 │                                │
                 ▼                                ▼
        L298N  电机电源 VCC              降压模块 MP1584/LM2596
        (12V, 峰值 2×2A)                 (12V → 5V, ≥2A)
                 │                                │
                 │                       ┌────────┼─────────────┐
                 ▼                       ▼        ▼             ▼
        OUT1/OUT2 → 左电机              │   Blue Pill      L298N 5V 脚
        OUT3/OUT4 → 右电机              │   5V 脚          (拆掉板载 5V
                                        │   (板载 AMS1117  跳线帽)
                                        │    → 3.3V)            │
                                        │        │              ▼
                                        │        ▼        L298N 内部逻辑
                                        │   3.3V 轨       (L298 芯片 VSS)
                                        │        │
                                        │   ┌────┴─────┬──────────┬─────────┐
                                        │   ▼          ▼          ▼         ▼
                                        │ OLED      MPU6050   QMC5883L   蜂鸣器/振动
                                        │ (3.3V)    (3.3V)    (3.3V)     (见注)
                                        └─►（可选）蓝牙模块 VCC
```

**要点：**

1. **主电源 = 12V**（3S 锂电组 9.0~12.6V 或 12V 铅酸/适配器）。**不用 2S**：12V 电机在 7.4V 下扭矩与转速都严重不足。
2. **L298N 的 5V 跳线帽必须拆掉**，5V 脚由降压模块供电（同一 5V 轨），原因：
   - 满电 12.6V > 12V，板载 78M05 线性稳压要消耗 (12.6−5)×I，发热严重；
   - 拆掉后 78M05 与 5V 轨隔离，逻辑电由降压模块提供，电流干净。
3. **L298N 压降约 2V**：12.6V 满电时电机实际约 10.6V，标称 12V 电机转速会略降（约 −12%），属正常，不必修正 PWM 逻辑。
4. **电机电源与控制电源分开馈电、星形接地**（电池负极是唯一汇点）。
5. 所有模块**必须共地**；电机线束与 I²C / 超声波信号线分开走。
6. **蜂鸣器/振动马达**：优先从 **3.3V 轨**接（电流小：蜂鸣器 <30mA、马达 <100mA）；若振动马达功率偏大（>200mA），改从 5V 轨供电，**切勿**挂 STM32 的 3.3V 引脚上取电。
7. **MCU 供电**：Blue Pill 的 **5V 脚**接降压模块输出（经板载 AMS1117 出 3.3V）；**不要**用 3.3V 脚反灌。
8. **电机噪声抑制（不做会莫名复位）**：每个电机端子并 **100nF 陶瓷**；电源入口并 **100µF/25V 电解**。

### 4.2 电池电压检测分压（PA4）

```
  V_bat (12V 轨) ──[ 33kΩ 1% ]──┬──[ 10kΩ 1% ]── GND
                                │
                                ├── 100nF ── GND
                                │
                                └──► PA4 (ADC1_IN4)
```

- 分压比 **(33+10)/10 = 4.3**；满电 12.6V → **2.93V**（< 3.3V ✅）；可测上限 14.19V（留有余量）。
- 计算式：`V_bat = ADC_RAW × 3.3 / 4095 × 4.3`
- 静态耗流 ≈ 12.6V / 43kΩ ≈ **0.29mA**（可忽略）。
- 分压中点阻抗 7.7kΩ，满足 STM32 ADC 源阻抗要求。
- **标定**：代码里放 `CFG_BATT_DIV_RATIO`（默认 4.30），上电后用万用表实测 V_bat 与 shell 读数对比，改参数即可（不需要动硬件）。

### 4.3 报警参数参考（3S 锂电，参数可在 shell 改）

| 等级 | 阈值（3S） | 动作 |
|------|-----------|------|
| 正常 | > 10.5V | 无 |
| 低电量告警 | 10.2 ~ 10.5V | 每 60s 短鸣 1 声 + OLED 显示电压 |
| 严重低电 | < 9.9V | 长鸣 1 声 + 每 10s 重复 + 提示尽快停止使用 |

> 若最终用 12V 铅酸，阈值完全不同（11.5V / 10.8V），届时改参数即可。

## 7. 风险与待办（阶段 1 输出）

| # | 风险/待定 | 影响 | 处置 |
|---|-----------|------|------|
| R1 | **L298N 单通道 2A** vs GA25-370 堵转电流（12V 常见 2~3A） | 堵转时超规格、发热 | 代码侧做**软启动 + 限速（默认 ≤70%）+ 禁止长时间堵转**；机械上避免顶死障碍物；必要时加散热片 |
| R2 | **12V 电源具体形态未定** | 影响续航、重量、电池仓设计 | 阶段 4 前需确认（3S 锂电组建议 ≥2000mAh、放电 ≥5A、带保护板 + 12.6V 充电器） |
| R3 | **OLED 控制器型号未定**（SSD1306 / SH1106） | 显示错位 2 列 | 阶段 4 交接驱动代码时确认；驱动适配层两者都留开关 |
| R4 | **超声波具体型号未定** | UART 模式 vs Trig/Echo 模式 | 驱动层两套都实现，用 `CFG_US_MODE` 切换；到货后按实际接线 |
| R5 | **I²C 上拉电阻并联过多**：OLED+MPU6050+QMC5883L 各带 4.7kΩ → 约 1.57kΩ | 极端情况下总线拉不下来 | 速率先配 **400kHz**；若扫描不稳定，降 100kHz 或拆掉多余模块的上拉电阻（只留一组） |
| R6 | **I²C 模块供电电平**：板上 LDO 需要 ≥3.5V 输入的模块在 3.3V 下可能不工作 | 设备无响应 | 统一先接 3.3V；若某模块不应答，改接 5V，并在 VERIFY 阶段实测 SDA/SCL 空闲电平 ≤3.3V |
| R7 | **USART3 被蓝牙占用**，v2 的 4G/WiFi 无 UART 可用 | 未来扩展受限 | 已知取舍；v2 若上联网模块，改走 SPI 或复用超声波 UART |
